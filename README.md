# LinguaFlow - Translation Services Website

A professional translation services website built with HTML, CSS, and JavaScript.

[https://anbu37377-afk.github.io/Translation-Services-website/](https://anbu37377-afk.github.io/Translation-Services-website/)

## 📋 Features
- **Responsive Design**: Works perfectly on all devices
- **Dark/Light Theme**: Toggle between themes
- **Multi-page Navigation**: Home, Services, Pricing, Contact, Blog, etc.
- **User Authentication**: Login and Signup functionality
- **Interactive Elements**: Smooth animations and transitions
- **Modern UI**: Clean and professional design

## 🔧 Setup Instructions

### Local Development
1. Clone this repository:
   ```bash
   git clone https://github.com/anbu37377-afk/Translation-Services-website.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Translation-Services-website
   ```

3. Open `index.html` in your browser or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   ```

4. Open your browser and visit `http://localhost:8000`

### GitHub Pages Deployment
This site is automatically deployed using GitHub Pages. Any changes pushed to the `main` branch will be automatically published.
